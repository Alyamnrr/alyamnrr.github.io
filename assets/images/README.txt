=======================================================
PANDUAN PENYIMPANAN GAMBAR PORTOFOLIO — ALYA
=======================================================

Folder ini khusus untuk menyimpan file gambar portofolio web kamu.
Cukup letakkan file gambar dengan nama-nama berikut di dalam folder ini:

1. FOTO PROFIL KAMU:
   Nama file: profile.jpg
   Ukuran ideal: 800x1000 px (Foto vertikal / portrait)
   *Tips: Kamu juga bisa klik ikon kamera di halaman web langsung untuk mengganti foto dari komputer/HP secara instan!

2. GAMBAR PROYEK 1 (RemindU):
   Nama file: project-remindu.jpg
   Ukuran ideal: 800x450 px (Landscape / screenshot aplikasi RemindU)

3. GAMBAR PROYEK 2 (Fuzzy Logic Delivery):
   Nama file: project-delivery.jpg
   Ukuran ideal: 800x450 px (Landscape / screenshot grafik fuzzy atau Google Colab)

Catatan:
Jika file gambar belum kamu masukkan, halaman web sudah otomatis memiliki gambar cadangan (fallback) yang estetik dan rapi, sehingga tidak akan ada gambar rusak (broken image).
